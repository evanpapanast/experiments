        Data, privacy and quality

        How the report was built, how personal data was kept out, and the checks that must pass before anything is published.

        How it was built

        1. AskWhich customer groups and channels drive profitable revenue, and where should next year's marketing go?
        2. ConnectGoogle BigQuery public data (TheLook), read through the BigQuery connector in Claude.
        3. ModelA dbt project on BigQuery: minimised staging tables, one group per customer, group-level report tables, with built-in cost caps.
        4. Check43 dbt tests in BigQuery plus a quality gate on the published files in GitHub Actions.
        5. ShipReviewed pull request, then published on GitHub Pages.

        GDPR: what was kept out

        • Data minimisation: only customer ID, age band, gender, region, first channel and sign-up month were copied. Names, email, street address, postal code, city, state, GPS position, exact age, IP address, browser and page addresses never left the public dataset.
        • No children: customers under 18 are excluded completely.
        • No single person can be seen: the report and data files hold group totals only. Every group has at least 50 customers; smaller cells are hidden.
        • Country removed: countries are grouped into four regions so that small countries cannot single anyone out.
        • Synthetic source: the data describes no real people. The same rules were applied as if it did.

        Definitions

        • Net revenue: value of items not cancelled and not returned. Items still processing or shipped count as sold.
        • Gross margin: net revenue minus the product cost of those items.
        • Return rate: returned value ÷ value of items not cancelled. Cancellation rate: cancelled value ÷ all ordered value.
        • Purchase channel: channel of the purchase visit closest in time to the order (within 24 hours); all orders matched.
        • Preferred channel: channel of most of a customer's visits; ties go to the most recent visit, then a fixed channel order, so every run gives the same answer.
        • Window: 20 Nov 2024 to 19 Nov 2026. The source grows every day, so the snapshot is frozen at 19 Nov 2026.
